# 🚨 SOS-ID.CHEBUR.SHOP | Devices & Emergency Profiles

Официальный веб-сайт магазина умных устройств экстренной связи и безопасности **SOS-ID.chebur.shop**, интегрированный с единой облачной медицинской платформой **[SOS-ID.online](https://www.sos-id.online)**.

---

## 📱 О проекте

Сайт предназначен для презентации и продажи умных экстренных аксессуаров:
* **QR-Браслеты** — силиконовые браслеты с гипоаллергенным покрытием для мгновенного доступа к профилю SOS.
* **GPS-Трекеры «Забота»** — компактные трекеры с кнопкой SOS, отслеживанием геопозиции и датчиком падения.
* **SOS-Брелоки** — металлические кулоны и брелоки с гравировкой QR-кода.

---

## ✨ Основные возможности сайта

1. **Мультиязычность (RU | UA | EN):** Полная поддержка переключения интерфейса и текстов заказов.
2. **Интерактивный слайдер:** Автоматическая демонстрация главных продуктов в шапке сайта.
3. **Встроенный видеоплеер:** Прямая трансляция презентационного видеоролика (promo.mp4).
4. **Быстрый заказ через WhatsApp:** Модальное окно заказа с автоматической формой отправки сообщения менеджеру.
5. **Адаптивный дизайн:** Корректное отображение на всех типах устройств.
